# LOGOS deployment checklist

## Supabase
1. Create a Supabase project.
2. Open SQL Editor and run `supabase/schema.sql` after reviewing it.
3. Configure Auth email confirmation.
4. Add your local and GitHub Pages URLs to Auth redirect URL allow-list.
5. Configure the storage buckets and policies required by the implemented app.
6. Assign the first administrator role manually through a trusted Supabase SQL Editor session after confirming the correct user ID.
7. Implement invite validation using a trusted Edge Function before enabling invite-only signup.

## GitHub
1. Create a repository and push the application.
2. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` as GitHub Actions repository variables (these are public client configuration values, not privileged secrets).
3. Enable GitHub Actions Pages deployment and grant Pages write permissions as required by the workflow.
4. Set Pages source to GitHub Actions.
5. Confirm the Vite base path equals `/<repository>/` for a project site.
6. Push to the configured branch and inspect the Actions run.

## n8n
1. Install/run n8n separately.
2. Configure credentials in the n8n UI.
3. Import workflow JSON if generated by the implementation agent, or build from `n8n/WORKFLOW_BLUEPRINT.md`.
4. Configure secure server-to-server triggers.
5. Test with dummy users and activate workflows only after successful validation.

## Before inviting classmates
- Test two members cannot edit each other's articles, profiles or comments.
- Test drafts are invisible to other members and anonymous visitors.
- Test admin-only moderation.
- Test invite token expiry/reuse rules.
- Test mobile layout and GitHub Pages deep links.
- Check browser network requests and repository history for secrets.
